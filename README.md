## 仕様

- 1資料1HTML。自己完結。外部依存は Google Fonts のみ
- 図表はページ内で生成（SVG）。画像ファイルなし
- ダークモード・スマートフォン・印刷に対応
- 数値には出典を明記。例示値はその旨を記載

## 更新

資料の編集は別のリポジトリで行い、配布用のHTMLのみをここへ複製する。
複製のときは次の2点を変換する。

- 一覧 `index-b.html` を `index.html` として置く
- 各回の一覧へのリンク（上端の `← 資料一覧` と末尾のナビ）`href="index-b.html"` を `href="index.html"` に置換

`.nojekyll` は Jekyll による加工を止めるために置いている。
