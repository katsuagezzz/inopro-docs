4年イノプロ　2026年11月2日　講義要点

空売りの仕組みとうねり投資

前半
サプライチェーン・上がる／下がる／動かない・空売り（iPhone と Apple株の例）・株価が急落する要因
後半
うねり投資とAIミニアプリ
提出
復習クイズ・毎週の株価
1

要点

前半 志村（サプライチェーン・空売り・株価の急落）、後半 秋山（うねり投資とAIミニアプリ）。

  • サプライチェーン　製品が消費者に届くまでに関わる会社の連なり。どこに一番お金が貯まるかを調べる
  • 3つの局面　上がれば買い、下がれば空売り（ショート）、動かなければオプション（次回）
  • 空売り　持っていない物を借りて先に売り、期日に買い戻して返す。値段の差が利益。「金利と時間」のファイナンス
  • 株価の急落　炎上 → 客足 → 売上 → 純利益 → 配当の予想 → 売り → 株価下落の連鎖を頭に入れる
  • うねり投資　上げ止まりと下げ止まりの間を往復する株を、下で買って上で売る。AIで銘柄探しを自動化
  • How より What　やり方（How）はAIで簡単になった。どの手法を選ぶか（What）の目利きが重くなる
2

サプライチェーン

「この言葉だけは覚えてほしい」。AIの製品が消費者に届くまでに多くの会社が関わり、お金が動く。

  • どこにお金が貯まるか　ROEなどの経済用語とAIツールで調べる。投資先と就職先（どこに身を置くか）の両方に使う
  • 利益の差　同じAIの会社でも営業利益は極端に違う。その差は株価にも給料にも表れる
  • 赤字の会社への販売　赤字の会社に物を売ると、代金が払われないかもしれない（未払いのリスク）

AIの会社の例は11月2日の資料 節2（Anthropic の上場申請書）。

3

空売りの仕組み①　iPhone の例

株は「ややこしい」ので、身近な物で。定価35万円の iPhone が、フリマアプリでは50万円で売れている。

  • iPhone を持っていないAさんが、店から「月末まで借りて、後で返す」約束で1台借りる（11月2日〜月末）
  • 借りた iPhone を、欲しいBさんに50万円で売る。Bさんは満足、Aさんの手元には50万円
  • 月末に、Aさんは店へ定価35万円を払う。店にとっては35万円で1台売れたのと同じ
  • Aさんに15万円が残る。誰も損をしていない
50万円 − 35万円 ＝ 15万円
  • 期限と負債　受け取った50万円は自由に使えるお金ではない。使い込んで期日に払えなければ、借りた相手への負債が残る
  • たとえの限界　この例は物を返す代わりに定価を払う形。株の空売りでは、株そのものを買い戻して返す（節4）
  • 市場の役割　市場があることで、今の値段と後の値段の違いが表に出る。「質屋と一緒」
4

空売りの仕組み②　Apple株の例

Apple株 500ドル。Aさんが空売りし、割安と考えるBさんが500ドルで買う。期日は11月30日。

  • Aさんは証券会社から株を借りて、Bさんに500ドルで売る
  • 今日の時点　Bさんは株を持ち、Aさんは現金500ドルを持つ。株は証券会社が1か月だけ貸した物
  • 11月30日に株を返す。証券会社に必要なのは株そのもので、株価がいくらかは関係ない
  • 上場株はAさんから買ってもBさんから買っても同じ。返すときは市場で誰からでも買える
  • 買い戻しの値段で損益が決まる
期日の株価と損益　1株・ドル
11月30日の株価買い戻し損益
300300＋200
400400＋100
5005000
600600−100

下がるほど儲かり、上がるほど損をする。株価に上限はないため損失にも上限なし。貸株料・追加保証金などは11月2日の資料 節3。

  • ファイナンスの型　空売りは「金利と時間」の仕組みの1つ。値上がりだけが資産を増やす手段ではない
  • 下落で儲ける人　下げ相場で利益を出している投資家は多い（小説 黒木亮『カラ売り屋』）
5

株価が急落する要因

学生から出た要因と、志村の補足。「もっと直接的に」と問い直した。

  • 業績　P/Lの悪化
  • 負債　負債が増える。ただし、なぜ増えるか、もっと直接のきっかけを考える
  • 新規事業への不安　成功しそうにない事業に大きなお金を使うと、投資家が売る
  • スキャンダル・異物混入　飲食チェーンの虫の混入、食品への異物混入などで炎上
炎上 → 客足が落ちる → 売上が落ちる → 純利益が下がる → 配当が減ると投資家が予想 → 株を売る → 株価が下がる

空売りの戦略

  • 時間　下がるのが半年後か、1か月で急落かを考える
  • 業種への広がり　1社の問題が同じ業種（回転ずし・外食チェーン）に広がるかを考える
  • 大きな出来事　中間選挙・地震・台風など、誰でも知っている社会の出来事で利益を出す投資家も多い
  • やってはいけないこと　株価を下げる目的で事件やうわさを仕掛けるのは犯罪（金融商品取引法の風説の流布・偽計）。授業の例は仕組みの説明

うねり投資とAIミニアプリ

後半 秋山。元にした本は上岡正明『働きながら1億貯める AI株式投資の全手順』。

  • How より What　やり方のハードルはAIで下がった。再現性があり自分に合う手法を選ぶ目利きが重くなる
  • うねり投資　何度も上げ止まった価格帯（レジスタンス）と、何度も下げ止まった価格帯（サポート）の間を上下する株を、下で買って上で売ることを繰り返す
  • 手順　10年分のチャートで同じ価格帯を往復する株を探す → 線を引く → 下がるまで待つ → 決算・ニュースを確認して買う → 待って売る
  • 銘柄の探し方（本の3つ）　著者がウォッチしている株を見る／AIに聞く／1社ずつ総当たりで見る
AIミニアプリの絞り込み
段階件数中身
株価を取得約1,600銘柄日米の株価
下落した株43銘柄簡易レポート
有望な株4件詳細レポート。収益性・持続性・確実性で評価し、リスクも挙げる
推奨1件買いの候補。現在値・買いの目安・売りの目安・チャート
  • 過去のデータで検証　10年分で勝率73%、平均＋10%程度（授業中の発表。要確認）
  • 画面　相場全体の確認／保有株の売り時のチェック／買い候補の選定
  • 費用　1回の株価の処理でAIの利用料がかなりかかる
  • 本の読ませ方　電子書籍は直接読めないため、内容をAIへの指示の材料として渡した

授業で名前の出た手法・数値は説明の例。投資の推奨ではない。

質問集

授業中に答えが出なかった・止まった問いを中心に。着地点は閉じてある。

授業の問いAIで調べた空売りの仕組みを説明できるか。（「なんとなく分かる」まで）
着地点

持っていない物（株）を借りて先に売り、期日に買い戻して返す。売った値段と買い戻した値段の差が損益。

授業の問い定価35万円の iPhone がフリマで50万円。儲けたいならどうするか。（約24秒の沈黙）
着地点

店から借りて50万円で売り、月末に定価35万円を払う。15万円が残る。

授業の問い売った直後、Aさんの手元には何が残るか。（答えが出なかった）
着地点

50万円。ただし月末に35万円を払う義務（負債）も残る。

学生の質問借りた物が売れなかったら、いつまでも持っていられるのか。
着地点

持っていられない。必ず期限がある。期日に返せなければ、借りた相手への負債が残る。

授業の問いApple株の空売りで、11月30日に株価がどうなっていればよいか。（答えが不完全）
着地点

500ドルより下がっていればよい。市場で買い戻して返し、差額が利益。400ドルなら100ドル。

授業の問い株価が急に下がる要因は何か。（「負債が増える」まで）
着地点

業績の悪化、新規事業への不安、スキャンダル、異物混入による炎上。きっかけから株価までの連鎖で考える。

授業の問い異物混入が起きると、どうなるか。（答えが出なかった）
着地点

炎上 → 客足 → 売上 → 純利益 → 配当の予想 → 売り → 株価の下落。

来週から考える問い株価が動かなくても儲かる取引は何か。
着地点

オプション。11月9日の資料 節4で扱う。

復習クイズ

11月2日 空売り　5問。授業で答えが止まった箇所から出題。Google フォームでも同じ問題を配布。正解は閉じてある。

問1空売り（ショート）の手順として正しいものはどれか。
  • 証券会社から株を買う → 値下がりを待つ → 証券会社に株を売り戻す
  • 証券会社から株を借りて売る → 期日までに市場で買い戻す → 証券会社に株を返す
  • 証券会社からお金を借りて株を買う → 期日に株を売る → お金を返す
  • 市場で株を買う → 値上がりしたら売る → 差額を証券会社に払う
正解

証券会社から株を借りて売る → 期日までに市場で買い戻す → 証券会社に株を返す 最初の手持ちはゼロ。返すのは現金ではなく株そのもの。

問2Apple株を500ドルで空売りした。期日（11月30日）の株価は400ドル。損益はいくらか。
  • 100ドルの損
  • 100ドルの得
  • 400ドルの得
  • 500ドルの得
正解

100ドルの得 売値 500 − 買い戻し 400 ＝ 100。

問3Apple株を500ドルで空売りした。期日（11月30日）の株価は600ドルに上がっていた。空売りした人はどうなるか。
  • 株価が下がるまで返却を延ばせる
  • 受け取った500ドルを返せば終わる
  • 600ドルで買い戻して株を返す。100ドルの損
  • 証券会社が値上がり分を負担する
正解

600ドルで買い戻して株を返す。100ドルの損 期日に株を返す義務は株価に関係なく残る。上がるほど損が膨らむ。

問4定価35万円の iPhone が、フリマアプリでは50万円で売れている。店から1台借りて50万円で売り、月末に店へ定価35万円を払った。手元に残る金額はいくらか。
  • 0円
  • 15万円
  • 35万円
  • 50万円
正解

15万円 50万 − 35万。店は定価で売れ、買い手は欲しい物を得て、誰も損をしない。

問5飲食チェーンで異物混入が発覚し、SNSで炎上した。株価が下がるまでの流れとして正しい順はどれか。
  • 売上減 → 炎上 → 株価下落 → 配当減の予測 → 客足減
  • 炎上 → 株価下落 → 客足減 → 売上減 → 純利益減
  • 炎上 → 客足減 → 売上減 → 純利益減 → 配当減の予測 → 売り → 株価下落
  • 炎上 → 純利益減 → 客足減 → 株価下落 → 売上減
正解

炎上 → 客足減 → 売上減 → 純利益減 → 配当減の予測 → 売り → 株価下落 P/L の上から下へ影響が伝わり、株価は最後。
